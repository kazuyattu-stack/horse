Horse Race Simulator (Unity)

機械学習モデルが予測した勝率と、実際のレースデータ(脚質・上がり速度など)をもとに、競馬のレースを Unity 上で 3D 再現するシミュレーターです。

概要
レースID を指定すると、そのレースの出走馬がスプラインで作ったコース上を走ります
各馬の速度は、実データの 上がり速度 と 脚質(逃げ/先行/差し/追込) から決まります
終盤は、モデルの 予測勝率(pred) の順位に少しずつ近づくよう補正されます
実際の競馬中継を参考にした、ゾーンで切り替わる 自動カメラワーク を実装しています
主な機能
レースシミュレーション(RaceVisualizer.cs)
脚質ごとのペース配分：逃げは序盤から飛ばし、追込は抑えて走る。序盤の差は距離が進むにつれて薄れる
終盤のスパート：ゴール手前 400m から、実データの上がり速度(失速率 fade_rate を考慮)へ滑らかに切り替え
予測順位への補正：終盤、現在順位と予測順位のずれに応じて速度を補正
馬同士の位置取り：内ラチ(柵)側へ寄りつつ、近くの馬と最低限の横間隔を保つ。前が詰まると減速する
走行演出：速度に応じた上下のバウンドと前後のピッチ
スタート演出：ファンファーレ → ゲート音 → 歓声 の順に再生してから発走
カメラワーク(ChangeCamera.cs)

先頭馬の進捗(0〜1)に応じてカメラを切り替えます。

進捗	カメラ
0 〜 10%	馬群を後ろから追う移動カメラ
10 〜 80%	コース脇に据えた固定カメラ(3か所)から馬群へパン
80% 〜	ゴール前の移動カメラ
注視点は「先頭馬」と「馬群の中心」をブレンドし、先頭が画面端に寄ったり後続が見切れたりしないようにしています
馬群の広がりに応じて画角(FOV)を自動調整します
バウンド演出を含まない「素の」位置を追うので、カメラが一緒に揺れません
動作環境
Unity 20XX.X.X <!-- 使用したバージョンに書き換える -->
Unity Splines パッケージ
使い方
Assets/horse_simulation_data.json にレースデータを置く(形式は下記)
シーン上で以下を用意する
コースの SplineContainer を RaceVisualizer に設定
馬のプレハブ(Cube.prefab)を horsePrefab に設定
Main Camera に ChangeCamera をアタッチし、racevisualizer に RaceVisualizer を設定
AudioSource を持つ People(歓声)、Trumpet(ファンファーレ)、Pistle(ゲート音)オブジェクトを配置
RaceVisualizer の targetRaceId に走らせたいレースIDを入力して再生
